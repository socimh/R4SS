# Downloaded life-expectancy data

This is the unchanged CSV downloaded on 29 October 2026 from:
https://ourworldindata.org/grapher/life-expectancy.csv

Source page: https://ourworldindata.org/grapher/life-expectancy

Attribution: Riley (2005); Zijdeman et al. (2015); HMD (2025); UN WPP (2024), with major processing by Our World in Data. Consult the source page for the original providers, full citations, and applicable licenses. Our World in Data's own work is licensed CC BY; third-party data remain subject to their providers' terms.

The saved file has 21,565 rows and four columns: Entity, Code, Year, and Life expectancy. Each row represents a place in a year. Entities include countries, territories, and aggregate regions. Values measure period life expectancy in years. Coverage spans 1543 to 2023, with different coverage across places. Missing geographic codes do not imply missing life-expectancy estimates.

This file is distinct from tidystata::lifeexp, the prepared World Bank-derived country snapshot used for the main examples. No rows, columns, or values were changed in this download. The live source may subsequently change; the book supplies this dated copy for reproducing its import lesson.
